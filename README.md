# Colaj desktop app

Installers for the Colaj desktop app for Mac and Windows. This repository holds the installers only.

Download the newest version from the [latest release](https://github.com/Colaj-Inc/colaj-desktop/releases/latest):

- Mac with Apple silicon: `Colaj-mac-apple-silicon.dmg`
- Mac with an Intel processor: `Colaj-mac-intel.dmg`
- Windows: `Colaj-windows-setup.exe`

Sign in with your Colaj account. Learn more at [colaj.ai](https://www.colaj.ai), or write to help@colaj.ai.
